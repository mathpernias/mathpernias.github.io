Four things I'm proud of

Real work done at iA: what the problem was, what I did, and what changed.

Security

Locking passwords in a digital safe

The problem

The login credentials our pipelines use to talk to the call-center platform were stored in plain sight in the tool's settings. Anyone with access could read them.

What I did

Moved every credential into a secure vault. Pipelines now ask the vault for access only at the moment they need it, and nothing sensitive is left in the code.

The result

No secret exposed anymore, no downtime, and a setup that meets the company's security standards.

Azure Key VaultOAuth2Azure Data Factory

Privacy

Realistic test data, with no real people in it

The problem

To test properly, developers need data that looks real. But copying real customer conversations into test environments puts personal information at risk.

What I did

Built a configurable tool that automatically finds and replaces personal details in complex, nested data, driven by simple rules instead of custom code.

The result

Teams test on realistic data while customer privacy stays protected.

Cost optimisation

Cutting infrastructure costs by 30%

The problem

Servers that fetch data from external services were sized by guesswork, and nobody knew how much capacity was really needed.

What I did

Measured how many requests each service really handles and how many it allows, then built a data-backed sizing recommendation.

The result

About 30% lower infrastructure cost, with the same performance.

Automation

Documentation that publishes itself

The problem

Documentation about data tables lived in scattered files and quickly went out of date, so people stopped trusting it.

What I did

Treated docs like code: written in Markdown next to the data definitions, reviewed in pull requests, and published automatically to the company SharePoint after each merge.

The result

One source of truth that updates itself. It is a proof of concept today, ready to roll out to more teams.
